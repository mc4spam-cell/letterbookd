Neuerscheinungen

Wozu es dient: Die literarischen Neuerscheinungen jede Woche verfolgen. Die Anwendung übernimmt automatisch die Auswahl von Le Monde des livres und liefert den Clubs so Ideen für Lektüren.

Ablauf

Ein Raster aus Karten, eine pro aktueller Neuerscheinung: Cover oder Bild, Titel in Anführungszeichen, Auszug und eine Aktionsleiste unten (Favoriten / zu einer Liste hinzufügen / vorschlagen / „Artikel lesen“).

Die Übernahme läuft einmal pro Woche im Hintergrund (Django-Scheduler).

Aktionsketten

Jede Zeile beschreibt einen Auslöser in der Oberfläche, das sich öffnende Modal/Formular und den erzielten Effekt.

AuslöserModal / FelderEffekt
Herz-Symbol—Fügt die Neuerscheinung deinen Favoriten hinzu bzw. entfernt sie. Ist sie noch kein Buch im Katalog, wird sie in diesem Moment dort aufgenommen.
Ordner-SymbolModal „Zu einer Liste hinzufügen“.Legt die Neuerscheinung in einer Liste ab (vorhandene oder neue).
Teilen-/Dreieck-SymbolModal „Dieses Buch vorschlagen“.Sendet einen privaten Vorschlag an ein Mitglied, dem du folgst.
Link „Artikel lesen“—Öffnet den Originalartikel von Le Monde in einem neuen Tab.
